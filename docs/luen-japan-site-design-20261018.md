### LUEN의 차별점 (카피 방향)

1. **서울 현장 팀.** 경쟁사 다수는 일본 회사가 한국 파트너를 쓰는 구조. LUEN은 한국 크리에이터와 직접 일하는 서울 팀.
2. **조회수가 아니라 행동.** 한국 사이트의 핵심 메시지 "조회수를 만드는 것과 구매를 만드는 것은 다릅니다"를 일본 기업 언어로 옮김 → 방문·예약·구매 설계.
3. **한일 양방향 실적.** 일본 크리에이터 × 한국 브랜드 캠페인(헤라헤라 → 서울 매장 성지순례, 라쿠텐 랭킹 1위 등)을 운영한 경험 = 크로스보더 방문·구매 전환을 실제로 만들어본 팀. (사례 활용 범위는 확인 필요, §9)

## 5. 資料請求 설계

### 5-1. 흐름

```
資料請求 버튼 → 폼 (최소 항목) → 제출 → /ja/thanks/ (PDF 즉시 다운로드 + 상담 예약 안내)
                                          └→ 팀 메일함에 리드 도착 → 1영업일 내 일본어 후속 메일
```

- **즉시 다운로드 방식.** 담당자가 바로 사내에 공유할 수 있어야 합니다. 메일 발송형은 스팸함 문제와 대기 이탈이 있습니다.
- 폼 하단 체크박스: 「オンライン相談も希望する」 — 문의 폼을 따로 두지 않고 한 폼에서 상담 희망까지 받습니다.

### 5-2. 폼 항목 (항목 수가 완료율을 좌우하므로 최소화)

| 항목 | 필수 |
|---|---|
| 会社名 | 필수 |
| お名前 | 필수 |
| メールアドレス (회사 메일) | 필수 |
| ご検討内容 (복수 선택: 韓国市場進出 / 訪日韓国人の集客 / EC・公式サイトでの販売 / 情報収集) | 필수 |
| 部署・役職 | 선택 |
| 電話番号 | 선택 |
| ご検討時期 | 선택 |
| オンライン相談も希望する | 선택 |
| 개인정보 동의 (국외 이전 포함) | 필수 |

### 5-3. 자료(PDF) 목차안 — 「LUEN 韓国クリエイターマーケティング サービス資料」

1. 表紙
2. 韓国市場と訪日韓国人の現状 (공식 통계 출처 명기)
3. 韓国の消費者の購買行動 (NAVER 검색, SNS)
4. LUENについて
5. サービス 3種
6. 韓国クリエイターネットワーク
7. 実績
8. 導入の流れ・期間
9. 料金の目安 (공개 시)
10. よくあるご質問
11. 会社概要・お問い合わせ

기존 일본어 회사소개서가 있으면 그걸 바탕으로, 없으면 Claude가 초안을 작성합니다.

### 5-4. 폼 수신

- Formspree에 **일본어 사이트 전용 폼**을 새로 만들어 한국 문의와 메일함·알림을 분리할 것을 추천합니다 (계정 작업 필요).
- 메일 제목: `[LUEN JA 資料請求] {会社名}`

## 6. 디자인 원칙

- **공유:** LUEN 로고, Warm Ivory / Deep Espresso / LUEN Orange, 오렌지 시그널 점, 여백감 (`docs/luen-design-system-v3.md`)
- **일본용 조정**
  - 본문 서체 Noto Sans JP 우선, 줄간격 넓게
  - 한국 CSS의 `word-break: keep-all`은 일본어를 줄바꿈하지 못하므로 일본어 페이지에서는 `auto-phrase`로 덮어쓰기
  - 정보 밀도 증가: 표, 숫자, 단계도, FAQ를 한국 사이트보다 많이
  - CTA는 오렌지 하나 — **資料請求**로 통일 (헤더, 각 섹션 끝, 플로팅 버튼)
- **문체:** です・ます체, 상대 회사는 「貴社」, 과장 금지 (「必ず」「No.1」 등 근거 없는 표현 금지)

## 7. 기술 설계

- 정적 HTML (GitHub Pages) — 한국 사이트와 같은 방식
- 일본어 페이지 전용 CSS 파일 1개를 추가해 공통 CSS 위에 덮어씀 (공통 CSS 수정 최소화)
- `hreflang`: `/` ↔ `/ja/` 상호 지정, `x-default`는 `/`
- 사이트맵에 `/ja/`, `/ja/privacy/` 추가 (`/ja/thanks/`는 `noindex`)
- 문의폼·FAQ 스크립트는 페이지 언어(`lang="ja"`)를 보고 일본어 메시지 출력
- 구조화 데이터: Organization, WebPage, FAQPage (일본어)

| 일본 개인정보보호법 처리방침 | APPI 기준 처리방침 작성 (§8-1) | 법률 문서라 공개 전 전문가 확인 권장 |
| GA 한국/일본 분리 측정 | 코드 구현, 이벤트 설계, 리포트 설정 가이드 (§8-2) | GA 관리 화면에서 맞춤 측정기준 등록 (화면 안내 제공) |

### 8-1. 일본어 개인정보처리방침 (`/ja/privacy/`) 구성

LUEN은 한국 회사이지만 일본 거주자의 개인정보를 받으므로 일본 개인정보보호법(APPI)과 한국 개인정보보호법이 모두 적용될 수 있습니다.

1. 事業者の名称・住所・代表者
2. 取得する個人情報と利用目的 (資料送付, 相談対応, 提案, サービス改善)
3. 第三者提供 (원칙적으로 하지 않음, 예외 명시)
4. **外国にある第三者への提供** — APPI 제28조. 동의를 받기 전에 ① 이전 국가명, ② 그 나라의 개인정보 보호제도 정보, ③ 받는 쪽의 보호 조치를 알려야 함
   - 대상: Formspree(미국, 폼 처리), Google(미국, GA 분석), LUEN 본사(한국)
   - 국가별 제도 정보는 개인정보보호위원회(PPC)의 외국 제도 조사 자료를 참조해 링크
5. 安全管理措置
6. 保有個人データの開示・訂正・利用停止等の請求手続
7. Cookie・アクセス解析 (GA)
8. お問い合わせ窓口
9. 制定日・改定日

### 8-2. GA 한국/일본 분리 측정

같은 GA4 속성(`G-QXBK6XEK7G`)을 유지하고, 언어 구분 값을 붙여 나눠 봅니다. 속성을 따로 만들면 한·일을 오가는 방문자 흐름이 끊깁니다.

| 설정 | 내용 |
|---|---|
| 콘텐츠 그룹 | 한국 페이지 `content_group: ko`, 일본 페이지 `content_group: ja` |
| 사용자 속성 | 선택창에서 고른 값을 `client_region` (ko/ja)으로 저장 → 방문자 단위로 분리 |
| 이벤트 | `region_select` (선택창), `document_request` (資料請求 완료, **핵심 이벤트**), `document_download` (PDF 클릭), `consult_request` (상담 희망 체크), 기존 `generate_lead`는 한국 문의 전용으로 유지 |
| 맞춤 측정기준 | `client_region` (사용자 범위), `site_language` (이벤트 범위) — GA 관리 화면에서 등록 |
| 리포트 | 비교 기능으로 ko/ja 나란히 보기, 탐색 리포트로 `/ja/` 방문 → 폼 시작 → 資料請求 퍼널 |
| Search Console | 페이지 필터 `/ja/`, 국가 필터 일본으로 일본어 검색 성과 분리 |
| 광고·캠페인 | 일본 캠페인 UTM 규칙: `utm_source`/`utm_medium`/`utm_campaign=ja_…` |

개인정보: 기존 원칙대로 폼에 입력한 값은 GA로 보내지 않습니다.

## 9. 구현 전에 필요한 정보

우선순위 순입니다.

1. **선택 방식:** §1의 A(팝업)인지 B(메인 = 선택 페이지)인지
2. **일본어로 상담할 사람:** 資料請求 후 일본어 메일·온라인 미팅을 누가 하나요? 사이트에서 「日本語で対応」을 약속할 수 있는지가 이걸로 정해집니다.
3. **타깃 업종 우선순위:** §2-1 중 가장 먼저 잡고 싶은 업종 1~2개
4. **신뢰 근거**
   - 일본 기업과 진행한 실적이 있나요?
   - 없다면 기존 사례(헤라헤라, 이케다×EDITA, YUKI, 마스부치×bibigo)를 "크로스보더 방문·구매 전환 실적"으로 일본 사이트에 써도 되나요?
   - 함께 일하는 한국 크리에이터 수 등 공개 가능한 숫자
5. **실행 범위**
   - 한국 크리에이터를 일본으로 초청(항공·숙박 포함)하는 것까지 하나요?
   - 한국 판매 채널(쿠팡, 올리브영, 네이버 스마트스토어 등) 연계도 하나요?
   - NAVER 블로그 체험단도 하나요?
6. **자료(PDF):** 기존 일본어 회사소개서·제안서가 있나요?
7. **가격:** 料金の目安을 공개할지
8. **회사 정보:** 일본 내 연락처(일본어 응대 메일, 전화, LINE 등)나 일본 법인이 있나요?
9. **Formspree:** 일본어 전용 폼을 새로 만들 수 있나요? (계정 접근 필요)
