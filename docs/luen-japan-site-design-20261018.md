## 1. 첫 화면 선택 방식 — A 확정

- `luenkorea.com/`은 지금 한국 홈페이지 그대로. 첫 방문 때만 "한국 클라이언트 / 日本のクライアント" 선택창이 위에 뜸
- 일본을 고르면 `/ja/`로 이동하고 선택이 기억됨 → 다음 방문부터 바로 `/ja/`
- 상단 메뉴·모바일 메뉴·푸터에 `JP` / `KR` 전환 버튼
- 사이트 내부 이동, `#contact` 같은 바로가기 링크, 검색엔진 봇에는 선택창을 띄우지 않음
- 이 부분은 같은 브랜치에 프로토타입이 있어 재사용 (`assets/js/region-gate.js`, `assets/css/luen-region.css`)

### LUEN의 차별점 (카피 방향)

1. **서울 현장 팀.** 경쟁사 다수는 일본 회사가 한국 파트너를 쓰는 구조. LUEN은 한국 크리에이터와 직접 일하는 서울 팀.
2. **조회수가 아니라 행동.** 한국 사이트의 핵심 메시지 "조회수를 만드는 것과 구매를 만드는 것은 다릅니다"를 일본 기업 언어로 옮김 → 방문·예약·구매 설계.
3. **채널을 목적에 맞게 조합.** YouTube(신뢰·설명), Instagram(확산·비주얼), NAVER(검색·구매 전 확인)를 목적별로 설계. 한국 소비자는 구매·방문 전에 NAVER에서 후기를 찾아보므로 NAVER가 빠지면 전환이 약해진다는 점을 강조.

### 포지셔닝 — "한국 현장에서 직접 실행하는 팀"

대표 의견: 한국 현지에서 일본 브랜드를 상대로 한국 마케팅을 하는 회사가 거의 없다 → 무기가 될 수 있다.

조사 결과 **방향은 맞고, "거의 없다"도 대체로 맞습니다. 다만 "전혀 없다"는 아닙니다.**

| 구분 | 회사 | 구조 |
|---|---|---|
| 일본 회사가 한국 파트너·지사를 씀 (다수) | ビーウェル(오사카), LIFE PEPPER, ウィンナビ, bibin(서울 지점), マイクロアド 제휴 | 일본 영업 → 한국 쪽 파트너 → 크리에이터 |
| 한국 기반으로 일본 기업 대상 (소수) | DNK KOREA (한국 회사, 일본어 사이트, Naver·체험단 실행), Ascent (한국 모회사 + 일본 자회사, 데이터·광고 중심) | 한국 팀이 직접 실행 |
| 한국 대행사 대부분은 반대 방향 | LIVO, WISEK, 골드오션, 3WELL 등 | 한국 브랜드 → 일본 진출 |

→ **"한국 현지 팀 × 일본 기업 × 한국 크리에이터·NAVER 전체"** 조합은 드뭅니다. 무기로 쓸 수 있습니다.

| 무기 | 일본 기업에게 주는 의미 | 카피 방향 |
|---|---|---|
| 서울 현장 팀이 직접 실행 | 한국 쪽 대행사를 한 번 더 거치지 않음 → 빠르고, 정보 손실이 없고, 비용 구조가 단순 | 「韓国側の代理店を挟まず、LUENが韓国クリエイターと直接進めます」 |

**쓰면 안 되는 표현:** 「唯一」「日本で唯一」「No.1」. DNK KOREA 같은 회사가 있으므로 사실이 아니고, 일본 경품표시법(景品表示法)상 근거 없는 최상급 표현은 문제가 됩니다.

**외국 회사라서 생기는 불안을 미리 없애기:** 일본 기업은 해외 회사와 거래할 때 ① 언어, ② 계약서, ③ 결제(엔화·해외송금), ④ 회사 실체를 걱정합니다. ①은 일본어 메일, ④는 会社概要로 해결하고, ②③은 §9에서 확인합니다.

사례를 게재하지 않으므로 신뢰는 ① 회사 실체(会社概要), ② 진행 방식의 구체성, ③ 資料의 완성도, ④ 공개 가능한 숫자(§9 확인)로 만듭니다.

### 8-1. 이메일 응대 흐름

| 시점 | 메일 | 내용 |
|---|---|---|
| 資料請求 후 1영업일 내 | ① お礼・ヒアリング | 자료 감사 + 견적을 위한 질문 5개 (업종·대상 지역/상품, 목적, 희망 시기, 예산 범위, 원하는 채널) |
| 답장 받은 후 | ② ご提案・お見積り | 크리에이터 구성안·진행 일정·견적 |
| 미팅 요청 시 | ③ お打ち合わせのご依頼への返信 | 메일로 진행 가능함을 안내, 미팅이 꼭 필요하면 통역 일정 확보 후 날짜 제안 |
| 사례 요청 시 | ④ 実績のご案内 | 대표가 개별 사례 자료를 첨부해 발송 |
| 무응답 7일 후 | ⑤ フォローアップ | 짧은 리마인드 1회 |
| 공통 | 일본어 서명 | 회사명·이름·메일·LINE·사이트 |

템플릿 원본은 구현 단계에서 `docs/ja-email-templates.md`에 일본어·한국어 대역으로 작성합니다.

**권장 (선택): 회사 도메인 메일** — 일본 B2B에서는 개인 Gmail보다 `contact@luenkorea.com` 같은 회사 도메인 메일의 신뢰도가 높습니다.

- 받기: 무료 메일 전달 서비스(ImprovMX 등)로 `contact@luenkorea.com` → `luen.lhg@gmail.com` 전달. 도메인 DNS에 MX 레코드 2개와 SPF(TXT) 1개 추가
- 보내기: Gmail 설정 → 계정 및 가져오기 → "다른 주소에서 메일 보내기"에 `contact@luenkorea.com` 추가. SMTP는 `smtp.gmail.com` + Google 앱 비밀번호(2단계 인증 필요)
- 한계: 무료 방식은 도메인 전자서명(DKIM)을 걸 수 없어 일부 회사 메일 필터에서 스팸 처리될 가능성이 조금 있음. 확실하게 하려면 유료 Google Workspace
- 출시 차단 요소는 아니며 나중에 해도 됩니다. 도메인을 산 업체(가비아, 카페24 등)를 알려주시면 단계별로 안내합니다.

**LINE:** 개인 LINE 대신 **LINE 공식계정 무료 플랜(コミュニケーションプラン, 월 0엔)** 을 추천합니다. 개인 계정과 업무가 분리되고, 일본어 자동 인사말·資料請求 링크 메뉴를 넣을 수 있습니다. 무료 플랜은 월 200건 일괄 발송 한도가 있지만 1:1 응대 위주라 충분합니다. 심사 없는 미인증 계정은 무료로 바로 만들 수 있습니다 (파란 인증 배지는 별도 심사).

### 8-2. 일본어 개인정보처리방침 (`/ja/privacy/`) 구성

LUEN은 한국 회사이지만 일본 거주자의 개인정보를 받으므로 일본 개인정보보호법(APPI)과 한국 개인정보보호법이 모두 적용될 수 있습니다.

1. 事業者の名称・住所・代表者
2. 取得する個人情報と利用目的 (資料送付, メールでのご相談対応, ご提案・お見積り, サービス改善)
3. 第三者提供 (원칙적으로 하지 않음, 예외 명시)
4. **外国にある第三者への提供** — APPI 제28조. 동의를 받기 전에 ① 이전 국가명, ② 그 나라의 개인정보 보호제도 정보, ③ 받는 쪽의 보호 조치를 알려야 함
   - 대상: Formspree(미국, 폼 처리), Google(미국, GA 분석·Gmail), LINE(일본/한국), LUEN 본사(한국)
   - 국가별 제도 정보는 개인정보보호위원회(PPC)의 외국 제도 조사 자료를 참조해 링크
5. 安全管理措置
6. 保有個人データの開示・訂正・利用停止等の請求手続
7. Cookie・アクセス解析 (GA)
8. お問い合わせ窓口 (`luen.lhg@gmail.com`)
9. 制定日・改定日

### 8-3. GA 한국/일본 분리 측정

같은 GA4 속성(`G-QXBK6XEK7G`)을 유지하고, 언어 구분 값을 붙여 나눠 봅니다. 속성을 따로 만들면 한·일을 오가는 방문자 흐름이 끊깁니다.

| 설정 | 내용 |
|---|---|
| 콘텐츠 그룹 | 한국 페이지 `content_group: ko`, 일본 페이지 `content_group: ja` |
| 사용자 속성 | 선택창에서 고른 값을 `client_region` (ko/ja)으로 저장 → 방문자 단위로 분리 |
| 이벤트 | `region_select` (선택창), `document_request` (資料請求 완료, **핵심 이벤트**, 업종 값 포함), `document_download` (PDF 클릭), `line_click` (LINE 링크), 기존 `generate_lead`는 한국 문의 전용으로 유지 |
| 맞춤 측정기준 | `client_region` (사용자 범위), `industry` (이벤트 범위) — GA 관리 화면에서 등록 |
| 리포트 | 비교 기능으로 ko/ja 나란히 보기, 탐색 리포트로 `/ja/` 방문 → 폼 시작 → 資料請求 퍼널, 업종별 資料請求 수 |
| Search Console | 페이지 필터 `/ja/`, 국가 필터 일본으로 일본어 검색 성과 분리 |
| 광고·캠페인 | 일본 캠페인 UTM 규칙: `utm_campaign=ja_{업종}_{내용}` |

개인정보: 기존 원칙대로 폼에 입력한 값(이름·메일 등)은 GA로 보내지 않습니다. 업종은 선택지 값이라 개인정보가 아니므로 전송합니다.
