# LUEN 홈페이지 개발·QA·배포 작업 원칙

마지막 합의: 2026-10-18. 적용 저장소: `marketingbrocompany-hash/LUEN` (**content-intelligence-hub는 별도 프로젝트**).

## 절대 원칙
1. **기존 기능과 디자인 보존**: 변경 전 HTML/CSS/JS 의존성, 현재 화면과 수정 대상 파일을 확인한다. 전체 파일 교체, 무검증 레거시 CSS 삭제, 강제 push, 브랜치 일괄 종료 금지.
2. **독립 브랜치 + 작은 PR**: `luen-preview` 최신 검증 SHA에서 한 가지 목적만 수정한다. 기존처럼 PR을 여러 기능 브랜치 위에 계속 쌓지 않는다. 기존 #138~#152는 먼저 영향 범위를 분석하며 임의로 정리하지 않는다.
3. **실험 코드 격리**: 속도·폰트·모션 실험은 독립 PR에서 전후 지표를 확인한다. 임시 패치가 검증 없이 일반 개발 브랜치에 들어가면 안 된다. 이미 들어간 실험도 독립적으로 재검증하고 운영 승인을 보류한다.
4. **운영 보호**: `main`, `luenkorea.com`, `www.luenkorea.com`, 운영 DNS/환경변수/배포 설정은 사용자 승인 없이 변경하지 않는다. `https://luen-preview.pages.dev`는 개발 검수용이며 운영과 구분한다.
5. **사실 기반 보고**: '구현', '자동 검사 통과', '실화면 QA 통과', '운영 반영'은 서로 다른 상태이다. GitHub CI Success, Vercel READY, 실제 사용자 화면 검증은 동의어가 아니다.

## 작업 순서 / 완료 기준
1. **사전 영향 분석**: 기준 SHA, 수정 파일과 호출 관계, 변경 이유, 사용자에 보이는 차이, 회귀 위험과 복구 방법 기록.
2. **구현**: 최소 diff, 새 브랜치, 단일 목적 PR. 이미 존재하는 기능·이미지·CTA·텍스트를 요청 없이 제거하지 않는다.
3. **코드 QA**: `node scripts/check-site.mjs`와 변경 파일 관련 테스트 실행; GitHub `LUEN static QA` 체크 통과 확인. 기존 링크·SEO·GA4·문의 전송 상태도 점검.
4. **실화면 QA**: 가능하면 PR별 독립 Vercel Preview에서 먼저 검증. 1440/1280/1024/820/768/430/390/360/320px 폭, 모바일 메뉴/스크롤/탭·키보드, 문구 줄바꿈, 이미지 크롭, 라운드 모서리, 움직이는 콘텐츠, reduce-motion, 주요 CTA와 내부 링크 확인. 실제 Safari/Android 실기기 미검증이면 미검증으로 표시.
5. **성능 QA**: 같은 환경에서 수정 전후 Lighthouse 반복 측정(모바일 최소 3, PC 최소 2회). 점수와 함께 **LCP, FCP, TBT, CLS, 요청 수/바이트, 시각 깜빡임**을 비교. 지표 하나 상승만으로 성공으로 판정하지 않는다. 악화된 지표는 기록해 재검증한다.
6. **통합**: 필수 검사에 통과한 작업만 `luen-preview`에 PR 병합; Cloudflare 개발 배포 후 전체 경로 및 문의 폼 **모의 응답** 검증. 브라우저 검증이 접근권한 문제로 불가능하면 통과했다고 주장하지 않는다. 문서만 변경한 PR에는 코드 QA만 적용 가능하다.
7. **운영 반영**: 승인된 릴리스 후보를 확정하고 최종 QA, 운영 반영 계획과 롤백 방법을 제시한 뒤 사용자 승인을 받아 `main`/공식 도메인에 반영한다. 준비됐다는 이유만으로 자동 운영 반영하지 않는다.

## LUEN 디자인 및 콘텐츠 유지 기준
- 따뜻한 아이보리·베이지 바탕, 오렌지 CTA, 부드러운 라운드 카드·이미지, 세련된 에디토리얼 서체.
- Brandazine처럼 살아 있는 스크롤 인터랙션을 참고하되 과도한 모션을 피하고 키보드·reduced-motion·모바일 사용성을 지킨다.
- 롱폼/숏폼 썸네일 움직임, 주요 Case Studies, 실제 성과 근거를 임의 제거/과장하지 않는다.
- `site.css`, `luen-v3.css`, `luen-finish.css` 등 다층 스타일의 우선순위를 확인하고 섹션별로 점진적으로 정리한다.
